## Исправленные проблемы

- В горизонтальном окне рендер использовал ширину вместо рассчитанного масштаба: корабль уходил за нижнюю границу. Рендер и движение теперь используют один масштаб, поле центрировано.
- Минимальная высота приложения обрезала короткие экраны; центрирование и запрет touch-прокрутки делали часть результатов недоступной. Высота согласована с viewport, интерфейсные экраны прокручиваются, игровое поле сохраняет `touch-action:none`.
- Логотип складывал символы в отдельные строки, и «Ж» выходила за рамку; символы размещены в одной строке.
- Safe area сохраняла старые положительные значения после сброса Telegram-отступов; восстановлен CSS `env()` fallback.
- Режим системного уменьшения движения не применялся к Canvas, игровой переключатель не отключал CSS-анимации. Уменьшены свечение и декоративные эффекты, отключены частицы и волна удара в этом режиме.
- Позиция музыки при паузе бралась из скорректированного игрового времени. Теперь сохраняется позиция аудиотранспорта, а ритм-поправка применяется отдельно и не накапливается при продолжениях.
- Незавершённый отсчёт продолжал издавать тики после паузы; запланированные тики останавливаются вместе с источником.
- Удержанные клавиши переносились через паузу; ввод очищается. Позднее или повторное завершение `resume()` больше не запускает игру после ухода в меню или деактивации.
- Загрузка, завершившаяся в фоне, запускала отсчёт; теперь требуется новое пользовательское нажатие. Остановка AudioContext переводит игру на паузу.
- Обычный текст ошибочно передавался в Telegram `shareMessage`, который требует ID PreparedInlineMessage. Существующий обмен текстом использует Web Share/буфер, отказ буфера обработан без необработанного Promise rejection.
- Старый `tests/smoke.cjs` обращался к элементам Neon Escape v1. Сценарий обновлён для текущей реализации и найденных сбоев.

Новые Node-регрессии проверены также на исходном коде: он их не проходит. Музыка, карта, движок, правила начисления очков, препятствия и общий визуальный стиль сохранены.

## Повторение проверок

Для Node-тестов установка пакетов не нужна:

```sh
npm test
node --check src/engine.js
node --check src/game.js
node --check tests/engine.test.js
node --check tests/browser-regressions.test.js
node --check tests/smoke.cjs
git diff --check
sha256sum assets/audio/neon-rush-140.mp3
```

Браузерный сценарий требует установленного Playwright и Chromium. Playwright доступен в среде этой проверки. Для отдельного окружения:

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
npm run test:browser
```

Можно указать `CHROMIUM_PATH`. Сценарий поднимает временный локальный сервер и закрывает его после проверки. Для локального HTTPS можно задать `TEST_SSL_CERT` и `TEST_SSL_KEY` с путями к тестовым сертификату и ключу; они не входят в репозиторий.
