# Этап 2.5 — пользовательский саундтрек VITTY

## Что сделано
- Для этой экспериментальной ветки подключён реальный загруженный пользователем аудиофайл `../makar-zhenya-soundtrack.mp3` из корня репозитория (Git blob `37246f4cde30c438a4b050a314ce7258232fc0ed`). Файл сохранён прежним, без копирования/перекодирования.
- Добавлен `assets/audio/vitty-track.json`: название `VITTY — Out Of My Mind (Original Mix)`, примерная оценка темпа 132 BPM, продолжительность 329.169 сек, проверочная сумма SHA-256. Старый трек Work `techno-rush-3d.mp3` более не запускается в этой сборке.
- В `src/course.js` игровая шкала увеличена с 192 долей до 724, а четыре музыкальные зоны распределены по отрезкам 0–180, 181–361, 362–542, 543–723. Это **условное деление**, а не подтверждённая ручная разметка музыкальных дропов.
- Скорость беговой анимации `src/character.js` согласована с новым количеством секунд на долю.
- Добавлено отображение настоящего названия саундтрека, 132 BPM в UI.
- Логика исправления паузы на iPhone из предыдущего этапа сохранена. Основная игра и ветка Work не менялись.

## Проверки
- Подтверждено совпадение локально доступного MP3 с файлом GitHub по blob SHA-1.
- Синтаксис `audio.js`, `app.js`, `course.js`, `character.js` проверен.
- Проверено: соответствие BPM/длительности/метаданных, путь к нужному файлу, отсутствие старого имени трека в коде загрузки, корректная смена зон.
- В модели игрового цикла полная трасса проходится без урона на 30 и 60 фиксированных кадрах/сек; это **не измерение FPS**.
- В `tests/course.test.js` обновлены проверки под новую продолжительность.

## Ограничения
- Фактическое воспроизведение/синхронизация на iPhone после изменений пока не подтверждены пользователем.
- Большой MP3 декодируется целиком в Web Audio; это может потребовать больше памяти на мобильном устройстве. Если будет задержка/закрытие страницы, следующий технический шаг — потоковое воспроизведение через HTMLAudioElement.
- Нет достоверной карты тактов и дропов оригинальной записи; используется оценка 132 BPM и нулевой beat offset. События могут идти не идеально в такт.
- Публичное использование коммерческого музыкального произведения требует прав или разрешения правообладателя. Доступность файла на GitHub не подтверждает наличие таких прав.
- Внешний вид персонажа и тоннеля пока не переделаны до желаемого качества; их художественная переработка — следующие этапы только по команде «го».
