# Музыка VITTY — этап 3A

Дата: 2026-10-09. Изменения только в ветке `feature/cosmic-rave-v2-graphics`.

## Исправлено
- В новой игре вместо синтезированного Work-трека `assets/audio/techno-rush-3d.mp3` теперь загружается исходный пользовательский файл `../makar-zhenya-soundtrack.mp3`, уже находящийся в корне репозитория.
- Подлинность проверяется SHA-256: `b74454eaff301ed1c32e451b92c39691a2f4be0d94d8334d979bfce85f0edc81`.
- Git blob SHA файла в репозитории: `37246f4cde30c438a4b050a314ce7258232fc0ed`.
- Длительность MP3 по ffprobe: 329.168980 с. Сетка 132 BPM × 724 доли = 329.090909 с (погрешность <0.08 с).
- Четыре зоны теперь начинаются на долях 0, 181, 362 и 543; забег охватывает весь трек.
- Игровой интерфейс показывает название композиции. Нет скрытой подмены музыки; ошибка загрузки отображается игроку.
- Добавлены тесты `tests/soundtrack.test.js` на SHA-256, метаданные, длительность и заполнение игровых зон.
- Обновлены версии импортов JS для обхода кэша на iPhone.

## Проверено
- SHA-256 и Git blob SHA локального исходного MP3 совпадают с сохранёнными значениями репозитория.
- Синтаксис всех изменённых JS-модулей проверен.
- 7 проверок сетки, игровых зон и прохождения длинного забега; 30 и 60 фиксированных шагов симуляции сохраняют 3 здоровья и корректный счёт.

## Не проверено
- Фактическое воспроизведение на физическом iPhone/в Telegram WebView, сетевые задержки загрузки MP3.
- BPM ≈132 — оценка, не ручная разметка сильных долей/дропов. Декоративные переходы между зонами пока не привязаны к реальным музыкальным секциям.
- Авторские права на публичное размещение пользовательского трека не подтверждены.
