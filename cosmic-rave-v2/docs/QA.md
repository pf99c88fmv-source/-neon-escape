# Проверки вертикального среза

Дата: 2026-10-09. Это отчёт о проверенных фактах, не подтверждение готовности релиза.

## Пройдены
- Синтаксис всех JS-модулей: node --check.
- 8 тестов node:test: направление Z, проходимость всех ворот, маршрут при 30/60 шагах
  в секунду, повреждение/восстановление/новый забег, режим без столкновений;
  остановка старого аудиоисточника, продолжение с позиции и пауза при отсчёте.
- GLB: Khronos glTF Validator — 0 ошибок, 6 предупреждений.
  Предупреждения: tangent space вычисляется при загрузке; skinned meshes имеют родителя.
  Полный машинный отчёт: gltf-validation.json.
- Исходная модель 35.19 МБ → 3.47 МБ; 7 клипов, скелет и текстуры сохранены.
- Музыка: MP3 декодируется ffmpeg, SHA-256 соответствует track.json.
- Анализ исходного трека: около 132.03 BPM, длительность 329.13 с.
  Метод: спектральный поток басового диапазона и автокорреляция по 8 периодам.
  Это автоматическая оценка, не ручная разметка дропов и не подтверждение прав.
- main остался на 686b422015ec931339dee714673c10ba37fd4823.
- Все новые пути находятся внутри cosmic-rave-v2/; существующие файлы не изменены.

## Блокирована визуальная проверка
Публичный независимый предпросмотр открывается; HTML/CSS/JS-модули загружаются.
Доступный облачный Chrome отказывает в создании WebGL:
`GL_VENDOR = Disabled, GL_RENDERER = Disabled; BindToCurrentSequence failed`.
Игровой цикл в этом браузере не стартовал. Снимок этого состояния не является
изображением работающей игры. Нет подтверждения запуска кнопкой, музыки после
жеста, визуального качества модели, рендера или отсутствия runtime-ошибок после
инициализации WebGL. Это обязательный следующий этап на WebGL-совместимом устройстве.

На физическом iPhone/Android/Telegram не тестировалось. 60 FPS не заявляются.
Автотесты с dt=1/60 не являются измерением производительности.

## Обязательный следующий проход
1. Открыть отдельный URL на iPhone 13 Safari, затем Telegram.
2. Проверить загрузку, полную видимость ног и отсутствие скольжения/деформаций.
3. 3 полных забега с перезапуском, паузой, блокировкой телефона и возвратом.
4. Проверить обе крайние дорожки коротким свайпом и второй палец/cancel.
5. Проверить музыка/сбор/щит/столкновения; отсутствие двойной музыки при рестарте.
6. Записать p50/p95 времени кадров, draw calls и память на каждом пресете.
7. Настроить камеру и анимации по видеозаписи; затем развивать четыре локации.
