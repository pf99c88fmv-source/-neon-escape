# МАКАР + ЖЕНЯ — COSMIC RAVE RUNNER

Независимый вертикальный срез. Не заменяет существующую игру.

## Запуск
Из этой директории: `python3 -m http.server 8080`.
Открыть http://localhost:8080. Требуются WebGL, Web Audio и доступ к CDN Three.js.
Музыка запускается кнопкой «Играть». Управление — короткий свайп или стрелки/A/D.
Пауза — кнопка или Escape. При сворачивании требуется явное продолжение.

Тесты: `node --test tests/*.test.js` (Node 20+).

## Публикация отдельно
Разместить содержимое только этой директории на отдельном статическом HTTPS-хостинге
или предпросмотре ветки. Не менять main, Pages workflow или корневые страницы.
Для Telegram Mini App указать отдельный HTTPS URL в настройках тестового бота.
Публичное имя бота задаётся через BotFather вручную; SDK не может переименовать бота.

Предпросмотр ветки: https://raw.githack.com/pf99c88fmv-source/-neon-escape/feature/cosmic-rave-v2/cosmic-rave-v2/index.html
Это тестовый CDN, не production-хостинг. Возврат к исходной игре: существующий /three.html,
он не меняется. Для возврата к конкретной новой сборке использовать URL с SHA коммита.

## Статус
Игровой цикл, оригинальная музыка, настоящий skinned GLB с бегом и танцем,
архитектурный тоннель, космический фон, три дорожки/свободное управление,
бонусы, щит, здоровье, комбо, локальные рекорды, пауза и перезапуск.
Четыре палитры/секции; это ещё не четыре законченные художественные локации.
Нет онлайн-таблицы, нескольких героев, финальных танцующих NPC или мобильной сертификации.
См. docs/AUDIT.md, docs/ASSETS.md и docs/QA.md.
